# План тестирования кнопок и флоу бота

## Цель
Проверить корректность работы всех кнопок во всех возможных состояниях и флоу, убедиться в сохранении состояния, возможности перегенерации, редактирования и отсутствии ошибок.

## Как использовать этот план

1. Проходите каждый раздел по порядку
2. Отмечайте [x] пройденные пункты
3. Записывайте найденные баги отдельно
4. Для каждого бага:
   - Описать шаги воспроизведения
   - Ожидаемое поведение
   - Фактическое поведение
   - Traceback (если есть)
   - Приоритет исправления

5. После исправления бага:
   - Повторить тест
   - Проверить связанные флоу
   - Убедиться, что исправление не сломало другие части
